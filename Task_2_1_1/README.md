#### Задача
В данной задаче реализованы 3 алгоритма
поиска составного числа в массиве простых чисел.

Алгоритм получает на вход массив чисел, возвращает:
- true - составное число найдено
- false - иначе 

#### Исследование скорости поиска
Проведено исследование скорости работы каждого из алгоритмов.
Для этого были сгенерированы 4 набора чисел:
1. массив длины 7 состоящий из очень маленьких чисел
2. массив длины 15 состоящий из последних максимально больших простых чисел, помещающихся в формат Integer
3. массив длины 10 000 состоящий из первых 10 000 простых чисел, идущих по
   возрастанию
4. массив длины 10 000 состоящий из последних максимально больших простых чисел, помещающихся в формат Integer

#### Исследование
Произведено измерение скорости работы каждого алгоритма
на каждом наборе данных. Для этого мы запустили алгоритм
20 раз и вычислили среднее время работы алгоритма `avg`
и 80% доверительный интервал `[tmin,tmax]`.
