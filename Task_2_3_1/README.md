# Задача "Змейка"
В данной задаче разработана игра Змейка при помощи JavaFX.

### Принцип работы

1. Змейка передвигается по полю размера M x N. В начале игры змейка состоит из одного звена.
2. Змейка перемещается по полю. В течение игры она может перемещаться вверх, вниз, вправо и влево, каждый раз поворачивая на 90 градусов в нужном направлении.
3. В течение игры на поле в случайных местах находится T элементов еды. Съев элемент еды, змейка вырастает на одно звено.
4. Если змейка попадает головой на препятствие или на свой хвост, то игра проиграна.
5. Для победы в игре необходимо достичь длины змейки в L звеньев.

### Запуск приложения

Запуск приложения осуществляется через терминал. Запуск производится из папки проекта. Необходимо выполнить следующие команды: 

```
./gradlew clean build
```
```
./gradlew run
```

### Вид приложения

Змейка в данной задаче - графическое приложение, которое запускается в отдельном окне. В данном окне появляются: 

1. Поле зеленого цвета 
2. Змейка с головой оранжевого цвета и хвостом кораллового цвета
3. Препятствия голубого цвета 
4. Элементы еды красного цвета 
5. При победе или поражении на экране появляются строки розового цвета с информацией
